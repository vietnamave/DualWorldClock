# Dual World Clock

デスクトップに、ふたつの世界時間を。

黒とシルバーの丸い文字盤に、水色とゴールドの秒針を組み合わせた、Windows用の無料デスクトップ時計です。
左右それぞれのタイムゾーンを選び、海外との仕事や日々の時刻確認に使えます。

## 機能

- 2つの丸いアナログ時計を画面右下に表示
- 時計ごとにタイムゾーンと表示名を設定
- 初期設定は東京とホーチミン
- 時・分・秒のデジタル表示（表示幅に合わせて文字サイズを調整）
- 日付・曜日は表示しない、すっきりした文字盤
- 大きさは25 / 50 / 75 / 100 / 125 / 150%から選択
- ドラッグ移動、最前面表示の切り替え
- 設定の保存、Windowsの規則に基づく夏時間の反映
- アプリ自身による通信・広告・利用状況の収集なし

## 対象環境と確認状況

Windows 10 / 11向けに作成しています。.NET Framework 4.xが必要です。
ソース配布版では、同フレームワークのC#コンパイラーも必要です。
対象OSは動作保証の範囲を示すものではありません。
開発環境ではWindowsでのコンパイル・実行テストを行えていません。
公開前に配布者のWindowsで起動・設定変更・終了を確認してください。

## 起動

1. ZIPを右クリックして「すべて展開」します。
2. 展開したフォルダーの `Start.cmd` をダブルクリックします。
3. 画面右下に2つの時計が表示されます。

実行ファイルが同梱されていないソース配布版では、初回起動時に実行ファイルを作成します。
フォルダーは、ドキュメントなど書き込みできる場所に置いてください。
実行ファイル同梱版は `DualWorldClock.exe` の直接起動もできます。
管理者権限やPythonなどの追加アプリは通常必要ありません。

## 操作

| 操作 | 内容 |
| --- | --- |
| 時計を右クリック → 時計の設定 | タイムゾーン・表示名・大きさ・最前面表示を変更 |
| 時計をダブルクリック | 設定画面を開く |
| ドラッグ | 2つの時計をまとめて移動 |
| 右クリック → 右下へ戻す | マウスがある画面の右下へ移動 |
| 右クリック → 終了 | アプリを終了 |
| 通知領域のアイコンをダブルクリック | 時計を再表示 |

次回起動時は画面右下へ表示します。移動位置は保存しません。
「デスクトップを表示」などで隠れた場合は、通知領域のアイコンから再表示してください。
25%は幅・高さが100%の1/4になります。文字はかなり小さくなります。

## 時計の精度

PCの現在時刻をもとにタイムゾーンを変換します。独立した時刻同期機能はありません。
時刻がずれる場合はWindowsの日時設定で同期してください。
夏時間はWindowsが保持するタイムゾーン規則に従います。

## 自動起動（任意）

一度起動して実行ファイルができた後、`DualWorldClock.exe` のショートカットを作成します。
Windowsキー＋Rで `shell:startup` を開き、ショートカットを入れてください。
元のアプリフォルダーは移動・削除しないでください。

## 更新・削除

更新前は現在の時計を右クリックして終了してください。
新しいZIPを別のフォルダーへ展開し、そこから起動します。
自動起動を設定している場合はショートカットも新しい実行ファイルに変更します。

削除する場合は時計を終了し、展開フォルダーと自動起動のショートカットを削除します。
設定も消す場合は `%LOCALAPPDATA%\DualWorldClock` フォルダーを削除してください。

## 開発・配布

- `DualWorldClock.cs`：C#ソース
- `Build.cmd`：Windowsで実行ファイルを作成（アプリを終了してから実行）
- `MakeRelease.cmd`：ビルド後、実行ファイルを含む配布用ZIPを作成

`MakeRelease.cmd` にはWindows PowerShellの `Compress-Archive` が必要です。
生成されるファイル名は `DualWorldClock-1.0.0-Windows.zip` です。
